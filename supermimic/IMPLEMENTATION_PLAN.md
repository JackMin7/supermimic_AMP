# 分阶段实施方案

## 完成定义

在 AMP_mjlab 的独立 SuperMimic 入口中，用真实 mjlab 数据训练世界模型，通过 BPTT 训练原速度控制 + AMP + 恢复任务，完成真实仿真对照、续训与 actor 导出。仅世界模型 loss 下降或想象奖励上涨不算完成。性能优于 PPO 是实验目标，不预设为既定结果。

## P0：基线冻结与评估协议

工作：记录 git、依赖、机器人模型、动作/观测/AMP feature schema；选择现有可用 PPO checkpoint；固定速度指令、倒地初态、推扰和随机种子。分别记录现有完整任务基线，以及和早期无推扰/简化任务相匹配的对照，避免错误归因。

产物：evaluation 场景配置、基线指标与原策略 ONNX trace。指标包括速度误差、存活时间、恢复成功率/耗时、足滑、动作变化和实际 GPU 时间。成功阈值在实验前固定。

验收：现有回放和导出可重现；恢复动作数据可读取；计时排除或单列编译与评估开销。此阶段不改 PPO 行为。

## P1：mjlab 适配与数据契约

工作：实现 adapters/mjlab.py、robot_schema.py、context.py；支持 Flat 环境，保留目标 Unitree 执行器。核对旧版本是否支持关闭 auto reset，不支持时使用局部环境子类/钩子捕获终止前状态。将 supermimic 加入打包配置。

实现可微 FK 与基础观测；从机器人模型按名称映射；读取实际 DR 值。特别区分 encoder bias 的传感器偏差语义与动作 setpoint 偏移，不将两者混用。

数据保存物理状态、执行动作、实际上下文、前后任务状态、episode_id、terminated、truncated、接触标签和 dynamics_valid。buffer 保存快照，不能保存会被仿真原地更新的引用。

验收：随机合法姿态下 FK、速度和观测与仿真逐项对齐；先消除坐标和时序系统误差，再根据数值精度固定容差。reset round-trip 正确；terminal next_state 未被 reset 覆盖；history 按 oldest→newest 排列；安装后可导入。

## P2：世界模型与序列 Replay

工作：迁入旋转工具、状态局部增量预测 MLP、running norm、8 步自回归损失与环形 replay。随机动作、现有 PPO 可用于诊断采集，但必须标识数据来源；最终主训练支持当前策略在线采集，不依赖教师。

先用固定或少量 DR、关闭随机推扰；恢复样本与站立/行走样本分别覆盖。序列不能跨 reset、buffer 环形时间边界或未建模扰动。按 episode/环境隔离验证数据，避免相邻窗口泄漏。

验收：报告 1/8/32 步物理量误差、姿态合法性、各动作类别误差及接触预测质量；优于零增量或简单运动学基线。32 步误差是诊断指标，不要求与单步同精度。不满足则先检查状态/上下文，不能靠加大网络掩盖接口问题。

## P3：可微训练闭环

工作：实现 core/runner.py、imagination.py、critic.py、checkpoint.py。从真实 replay 状态和同 episode 历史开始，H=32，GAE lambda=0.95，critic bootstrap；WM 和 critic 参数冻结而输入导数保留。首先使用少量平地参考动作做 tracking 冒烟验证，再接速度任务的可微基础奖励。

Tracking 只用于隔离验证，不要求先训练完整 LAFAN1 或把 tracking checkpoint 作为 AMP 前置依赖。短片段不足 rollout 长度时明确截断/过滤，禁止无限重采样。

验收：小型确定性例子的有限差分与 autograd 方向一致；actor 更新时 WM/critic 参数不变；真实 rollout 达到预先固定的 PPO 可比容差；检查 imagined/real reward gap、NaN、梯度范数。所有任务简化必须写入运行配置，不能与完整 AMP 基线直接比。

## P4：完整 AMP 与跌倒恢复

工作：新增可微 AMP reward 接口，沿用目标判别器特征、normalizer、损失与 reward lerp。原 predict_amp_reward 的 no_grad 路径留给 PPO。判别器用真实策略/专家 transition 更新，想象阶段冻结参数与统计。

实现恢复计数和奖励模式：40% 延迟环境、最多 250 个连续违规步、恢复清零、timeout 不延期；按目标实现推进。heading 控制要从想象朝向重新计算，命令重采样边界显式处理。奖励开关、平滑终止为训练代理，硬终止用于真实评估。

逐项实现目标奖励：速度、高度、动作变化、关节限位、终止惩罚；接触辅助头用于足滑和自碰撞。加速度有限差分、接触概率和软终止的近似单独记录并消融。奖励/观测比较需对齐读取时刻，不能只比较总和。

恢复完整 DR。推扰作为明确外生事件处理，或屏蔽跨扰动动力学窗口并从扰动后真实状态启动 imagination；不得将隐藏随机跳变当作可预测动力学。完整任务评估始终包含推扰。

验收：同一真实状态上可微 AMP 与旧接口前向数值对齐，输入梯度有效；真实恢复成功率可测；恢复计数、奖励模式、timeout 逐步对齐。速度与恢复不能仅改善其中之一。监测判别器饱和与模型漏洞利用。

## P5：对照、续训和部署

工作：比较 AMP-PPO、WMRL 基础任务消融、WMRL+AMP、WMRL+AMP+恢复；只有同任务配置才能作算法效率结论。资源允许至少 3 个种子，先小规模确定预算再扩展。

记录达到预先定义目标性能的 GPU 小时、真实步数、峰值显存，以及速度/恢复/足滑指标。汇报未达到目标的运行，不只选最优 seed。

实现 checkpoint 版本检查、保存加载、buffer refill；导出 actor 与归一化，验证 PyTorch/ONNX 同输入结果和闭环 rollout。确认部署输入历史排序、关节映射和 action scale 一致。

验收：完整配置可训练/评估/恢复/导出；得到真实仿真对比报告。若不优于 PPO，明确性能瓶颈与消融结果，不宣称复现论文加速倍数。

## P6：可选扩展（不阻塞 Flat 交付）

Rough：增加地形表示，依据想象位置更新 height scan，扩充接触监督并重做状态/奖励校验。

论文多接口：motion encoder + shared decoder + velocity encoder，定义 encoder-only 更新与 latent alignment，单独比较部署兼容性。

## 顺序与里程碑

P0 → P1 → P2 → P3 → P4 → P5；P6 单独立项。

- M1（P1 完成）：数据和几何可信。
- M2（P2 完成）：目标执行器下世界模型可验证。
- M3（P3 完成）：BPTT 在真实仿真中达到 PPO 可比容差。
- M4（P4 完成）：完整 AMP 走跑与恢复闭环。
- M5（P5 完成）：可复现实验、续训与导出交付。

每阶段的门槛不通过就定位原因，不直接扩大 batch 或进入长时间训练。当前进度：P0 的固定速度/恢复场景评分已完成（3 个种子，39 个 episode），确定性推扰协议仍属后续评估范围；P1 的物理采集、上下文、可微 FK、终止 actor 历史和接触监督已通过 GPU 检查。P2 已完成小规模离线动力学诊断：32,768 条 transition、500 次更新、独立环境 1/8/32 步验证，报告见 reports/p2_world_model.md；长时域倒地预测仍需改善。P3 已实现 H=8 BPTT、GAE critic 与配对真实评估，并开展 bootstrap 开/关消融；工程检查已通过，但两种变体真实平均回报分别变化 -0.016%/-0.020%，均未通过收益门槛，详见 reports/p3_bptt.md。用户已将验收目标调整为媲美 PPO，无需超越。历史收益门槛判定保留；按新工程容差，两项离线试验均通过回溯比较。P3 在线采集、世界模型刷新和交替更新已完成小规模验证：100 次 actor/critic 更新、200 次 WM 更新、16,896 条真实 transition；学习率 1e-6 首轮因 XY 误差和恢复退化失败，1e-7 复验在新种子 72/73/74 上逐种子及汇总均通过新容差（回报 -0.129%、XY +1.98%、yaw -0.43%、存活和恢复均 100%）。两次尝试完整保留，见 reports/p3_online_initial.md 与 reports/p3_online.md。下一阶段进入 P4 完整 AMP/恢复。新运行前固定容差：平均任务回报下降不超过 2%，XY/yaw RMSE 各增加不超过 5%，存活率与恢复成功率不下降。这是有限场景的工程验收，不是统计等效证明。


### P4 当前实现范围

已接入可微 AMP、真实策略/专家判别器更新、恢复计数和完整任务奖励代理；加入 heading 更新及显式恢复 critic 状态。数值对齐与梯度检查见 reports/p4_parity.json、reports/p4_gradient.json。训练更新时审计参数/统计隔离，验证环境不进入 WM、actor 或判别器训练采样。

真实评估使用共同冻结的原 PPO 判别器，对完整混合回报的速度/恢复两部分分别加 2% 容差，并保留 P3 的速度误差和成功率门槛。确定性推扰评估已接入；完整随机推扰训练、代理奖励消融、多训练种子及长训练仍属于 P4/P5 后续验证，不因一次小规模通过而宣称全部完成。

P4 小规模诊断结果已完成：100 次 actor/critic/判别器更新、200 次 WM 更新、16,896 条真实 transition。三组固定场景及一组固定推扰的单组和汇总验收均通过。固定场景完整 AMP 速度回报 -0.081%、恢复回报 +2.94%；恢复成功率 23/24 → 24/24，速度存活率保持 100%。14 项单元测试、逐项奖励/AMP 前向及端到端 actor 梯度检查通过。见 reports/p4_amp_recovery.md。P4 核心闭环已具备；上文列出的随机推扰训练、代理消融与多种子长训练验证仍未完成。


性能阶段：新增 train_fast，合并时域 FK/AMP 奖励、编译 tensor 核心、GPU AMP 统计、批量日志与周期审计；实现原子 checkpoint 及 replay/优化器/RNG 续训（新仿真 episode 边界）。64 环境同配置稳定单轮 2.361 → 0.138 秒；512 环境 batch 512 基准 0.201 秒。FP32 数值及梯度、16 项测试与实际续训检查通过。真实回归有效配对通过，但 seed 83 原 PPO 基线非有限导致该组无效，不能标记全组通过。详见 reports/performance.md。
