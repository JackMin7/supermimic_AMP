# P4 性能优化实测

单张 NVIDIA RTX 4090。相同 64 环境 / batch 128 / H=8 的热身后分段基准，单轮从 2.361 s 降到 0.138 s，约 17.1 倍。扩大至 512 环境 / batch 512 后约 0.201 s/轮。

| 路径 | 环境数 | actor/WM batch | 单轮秒数 |
|---|---:|---:|---:|
| 原诊断路径 | 64 | 128 | 2.3608 |
| 共享 FK，未编译 | 64 | 128 | 0.4695 |
| 共享 FK，编译 FP32 | 64 | 128 | 0.1379 |
| 扩大规模，编译 FP32 | 512 | 512 | 0.2006 |

基准固定 H=8、每轮两步真实采集、两次 WM 更新、一次判别器/actor 更新和相同 critic 更新次数。预热两轮后计时五轮，各段显式同步；编译冷启动不计入稳定吞吐。512 配置每轮数据更多，不能当作与 64 配置相同的数据预算。

## 正式入口验证

- 64 环境实际运行 100 次更新，稳定日志区间中位数 6.23 轮/秒；采集 16,896 条 transition；数值保护重置 0 次，全部留存日志。
- 512 环境实际运行 100 次更新，稳定日志区间中位数 6.88 轮/秒；采集 135,168 条 transition；数值保护重置 4 次，全部留存日志。

正式入口没有基准中的逐段同步，物理接触数量也随轨迹改变，故吞吐与微基准不同。14,000 次训练按实测估计约 35–50 分钟，加首次编译、保存和最终评估建议预留 45–70 分钟；这不是 14,000 次完整实跑结果。

## 数值、梯度与续训

- 编译 FP32 奖励最大差异 1.90e-7，actor 梯度相对 L2 差异 3.13e-7。critic 输入因量纲不同使用 rtol=1e-5、atol=2e-5 检查，相对 L2 差异 3.50e-7。
- TF32 与 BF16 的 actor 梯度相对差异分别约 5.89e-4、4.27e-3；均未满足完整严格 FP32 对齐标准，保留实验开关，默认不开启。
- 16 项测试通过。实际从第 6 轮恢复至第 8 轮，所有优化器步数和专家游标延续正确，新 episode ID 大于原 replay 最大值。
- 周期 checkpoint 原子替换；完整 last.pt 包含 replay。续训重置模拟器并 refill，不声称模拟器逐位恢复。

## 真实仿真回归

| 种子 | 推扰步 | 结果 |
|---:|---:|---|
| 82 | None | 通过 |
| 82 | 250 | 通过 |
| 83 | None | 无效：原 PPO 基线非有限动作 |
| 84 | None | 通过 |

候选在三组固定初态中均完成运行，速度存活率和恢复成功率均为 100%；有效配对（82、84 和 82 推扰）满足预设容差。83 的原 PPO 基线在约第 211 步出现非有限动作，该组明确标记无效，**整套真实回归不标记为全部通过**。没有通过改变验收线或丢弃失败来宣称成功。

独立评估还发现原派生状态哈希受 TorchScript 数值舍入影响：原始 qpos/qvel 和物理上下文完全相同，世界角速度变换相差 2.38e-7。现改为哈希原始仿真状态，计分前统一预热数学内核。初始失败诊断保存在 perf_evaluation_diagnostics.json。
